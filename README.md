# 위인을 찾아서

**즐귀도 음악 시간** — 초등학교 2학년과 함께 노래를 듣고 우리 역사 속 인물을 찾아보는 수업용 웹 앱입니다.

## 수업 흐름

1. 첫 화면에서 **탐험 시작하기**를 누릅니다.
2. 밀크T의 「한국을 빛낸 100명의 위인들」을 함께 듣고 따라 부릅니다.
3. 영상이 끝나기 전에도 **인물 찾아보기**로 넘어갈 수 있습니다.
4. 1~5절 노랫말에서 파란 이름을 누르면 오른쪽에 사진과 쉬운 설명이 열립니다.
5. **날개 닫기** 또는 Esc 키를 누르면 노랫말로 돌아옵니다.

## GitHub Pages로 배포하기

앱에는 별도 서버, 로그인, API 키, 유료 서비스가 필요하지 않습니다.

최신 앱 파일은 저장소 최상위에 있습니다. 별도 빌드는 필요하지 않습니다.

1. 저장소 **Settings → Pages → Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
2. 브랜치는 **main**, 폴더는 **/(root)**를 선택하고 저장합니다.
3. 배포가 완료되면 Pages 설정에 표시되는 주소로 접속합니다.

인물 찾아보기 화면을 바로 전달하려면 앱 주소 뒤에 **#lyrics**를 붙입니다. 각 절은 **#verse-1**부터 **#verse-5**, 영상은 **#video**입니다.

## 내 컴퓨터에서 보기

Node.js가 설치된 컴퓨터에서 이 폴더를 열고 `npm start`를 실행한 다음, 표시된 주소로 접속합니다. 현재 기본 주소는 `http://127.0.0.1:4180`입니다. HTML 파일을 더블클릭하는 방식은 사용하지 않습니다. 브라우저가 모듈과 사진 목록 파일을 읽으려면 웹 주소로 열어야 합니다.

`npm run check`로 노랫말 연결과 이미지 파일을 확인할 수 있습니다. 설치할 패키지는 없습니다.

## 수업 자료와 설명

- 노랫말: 요청자가 제공한 1~5절을 수록했습니다.
- 영상: https://www.youtube.com/watch?v=fP7sVxEUJ7g (밀크T 인기송). 영상 파일을 복제하지 않고 YouTube 플레이어를 사용합니다.
- 설명: 저학년 수준으로 새로 쓴 설명입니다. 실제 인물, 건국 신화, 전해 오는 이야기, 소설 속 인물, 여러 사람을 가리키는 말을 구분합니다.
- 인물 이름 77개 항목과 ‘태정태세문단세’에서 살펴볼 왕 7개 항목을 준비했습니다. 여러 사람을 가리키는 항목이 있으므로 이 수는 노래 제목의 100명과 같은 뜻이 아닙니다.
- ‘천태종’ 속 ‘태종’처럼 사람 이름이 아닌 낱말 일부는 인물로 표시하지 않습니다.
- 이름 위에는 나라나 인물 유형을 표시하며, 연도는 표시하지 않습니다.
- 이완용과 김두한 등은 모든 행동을 본받을 대상으로 소개하지 않습니다.
- 인물 사진은 초상·동상·유적·관련 자료를 포함합니다. 실제 얼굴을 촬영한 사진처럼 단정하지 않습니다.

## 사진과 글꼴 출처

사진별 파일명, 저작자, 원본 출처, 이용 조건을 `assets.json`에 기록했고, 앱의 사진 아래 **사진 출처와 이용 조건**에서도 볼 수 있습니다. 사진은 각 파일에 표시된 개별 라이선스를 따릅니다. 앱 전체에 하나의 라이선스를 일괄 적용하지 않습니다. 그림의 원본과 촬영·복제물의 권리가 다를 수 있으므로 원본 링크에 표시된 정보를 함께 확인하세요.

첫 화면의 책·산·궁궐 그림은 이 앱을 위해 만든 SVG입니다. 글꼴은 Google Fonts의 Jua와 Noto Sans KR을 불러오며, 연결되지 않으면 기기의 한글 글꼴을 사용합니다. YouTube 영상과 외부 링크는 인터넷 연결이 필요합니다. 인물 설명과 저장된 사진은 외부 사진 서버를 실시간 조회하지 않습니다.

## 파일 구성

- `index.html`: 세 화면과 수업 안내
- `style.css`: 색상, 글꼴, 반응형 화면
- `data.mjs`: 인물 설명과 노랫말
- `app.mjs`: 화면 이동, 이름 연결, 이야기 날개
- `assets/`, `assets.json`: 사진과 출처
- `.github/workflows/pages.yml`: GitHub Pages 배포
- `tools/`: 미리보기와 점검 도구

학생 이름이나 수업 기록을 서버에 저장하지 않습니다. ‘오늘 만난 이야기’는 새로고침하면 초기화됩니다.


## 저학년 설명과 100명을 세는 방법

어린이에게는 쉬운 설명과 ‘우리에게 준 도움 · 배울 점’ 한 문장을 먼저 보여 줍니다. 역사적 배경은 ‘조금 더 알아보기’를 펼치면 읽을 수 있습니다. 잘못을 살펴볼 인물과 소설 속 인물은 별도 문구로 생각할 점을 제시합니다.

개인 이름 71명 + 죽림칠현 7명 + 조선의 첫 일곱 왕 7명 + 사육신 6명 + 생육신 6명 + 삼학사 3명 = 100명으로 세는 방식입니다. ‘삼십삼인 손병희’는 손병희를 가리키는 구절로 세며, 민족대표 33명을 추가로 모두 더하지 않습니다. 앱의 클릭 항목 77개는 개인 71개와 묶음 5개, 보충 설명인 삼십삼인 1개를 합한 수입니다.


## 재검토한 설명 기준

파란색은 인물 설명을 여는 표시이며 좋은 사람이라는 판정이 아닙니다. 빨간색은 이완용의 국권 침탈 협력 행위를 별도로 기억하기 위한 표시로 한정했습니다. 정중부·신숙주·한명회·세조는 파란색으로 되돌렸습니다. 무신 차별과 정변의 폭력, 학문·외교 활동과 정치적 선택, 제도 정비와 왕위 획득 과정 등을 구분해 설명합니다.

모든 인물에게 억지로 긍정적인 교훈을 붙이지 않습니다. 기록에 근거한 행동과 생활에 준 도움, 수업에서 던지는 질문, 신화·소설·전해 오는 이야기를 구분합니다. 인물 전체를 착하다·나쁘다로 판정하거나 전쟁 참여·희생 자체를 본받을 행동으로 설명하지 않습니다.

노랫말과 연결한 설명은 개별 인물의 선정 이유를 작사가의 발언으로 단정하지 않습니다. 작사가 인터뷰의 일반적 취지와 수업용 해석은 구별합니다.

전체 문장 검토의 범위와 한계, 변경 이유는 CONTENT-REVIEW.md에, 추가로 대조한 쟁점별 자료는 references.mjs와 인물 날개에 있습니다. 역사 전문가의 감수나 모든 생애 사실에 대한 독립적인 전수 검증을 받은 자료라는 뜻은 아닙니다.

## 화면별 바로가기와 노래 재생

같은 배포 주소 뒤에 `#home`(시작), `#video`(영상), `#lyrics`(인물 찾기)를 붙여 직접 열 수 있습니다. 예를 들어 `https://사용자.github.io/저장소/#lyrics`는 첫 화면을 거치지 않고 인물 찾기를 엽니다. `#verse-3`처럼 절을 지정해 열 수도 있습니다. 이 주소는 시작 화면을 고르는 바로가기이며 다른 화면을 차단하는 접근 제한 기능은 아닙니다.

인물 찾기 상단의 버튼으로 노래를 재생·일시정지하며, 처음부터 재생 버튼으로 노래를 다시 시작할 수 있습니다. 다른 수업 화면으로 이동하면 멈춥니다.

날개는 본문 배치를 바꾸지 않고 겹쳐 열립니다. 조선의 첫 일곱 왕은 설명 상단에서 다른 왕을 바로 고르거나 돌아가기로 묶음 설명을 다시 볼 수 있습니다.


## 노랫말 출력

하단의 노랫말 출력하기 버튼은 브라우저 인쇄창을 엽니다. A4 세로 방향, 약 16pt, 흰 배경의 두 장으로 구성합니다. 첫 장은 1~2절, 둘째 장은 3~5절이며, 인물 강조를 유지합니다. 각 절을 하나의 단위로 묶어 절 중간에서 페이지가 끊기지 않게 했습니다. 인쇄 설정은 A4와 배율 100%를 권장합니다. 화면의 글씨 크기 조절은 출력 글씨 크기에 영향을 주지 않습니다.

인쇄 두 번째 장에는 제목을 반복하지 않고 줄 간격을 넓혔습니다. 처음부터 재생 아이콘은 재생 위치가 1초를 지난 재생·일시정지 상태에서만 재생 버튼 옆에 나타납니다. 절 선택은 중앙에 고정됩니다.

현재 출력 글자 크기는 15pt이며, 돌아가기 아이콘은 17px입니다. 아이콘을 누르면 처음으로 이동하고 일시정지하여 재생 버튼을 다시 누르기 전까지 재생하지 않습니다.

## 우리 반 노랫말 만들기

네 번째 페이지 `#compose`에 음절 칸 입력, 1~5절 펼침, 반주, 저장·출력·초기화, 이전 제작 기록을 추가했습니다. 기본 글꼴만 사용합니다. 온라인 저장은 Google Apps Script와 Google Sheets를 사용하며 [구글 저장소 연결 안내](google-apps-script/SETUP.md)를 따릅니다. 저장소를 연결하기 전에는 초안만 현재 기기에 임시 보관하고 공동 저장이 완료됐다고 표시하지 않습니다.
