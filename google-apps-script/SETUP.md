# 구글 Apps Script 저장소 연결하기

이 앱은 GitHub Pages에서 열고, 노랫말과 이전 제작 기록은 선생님의 구글 시트에 보관합니다. 별도의 Supabase 프로젝트는 사용하지 않습니다.

## 처음 한 번만 설정해요

1. [Apps Script](https://script.google.com/home/start)에서 **새 프로젝트**를 만듭니다.
2. 기본 `Code.gs`의 내용을 지우고 이 폴더의 [Code.gs](Code.gs) 내용을 전부 붙여 넣은 뒤 저장합니다.
3. 위쪽 함수 선택에서 **setup**을 선택하고 **실행**합니다. 이 스크립트가 새 저장 시트를 만들 수 있도록 선생님 계정으로 권한을 승인합니다. 학교 관리 계정에서 제한하면 관리자의 허용 또는 사용 가능한 다른 계정이 필요합니다.
4. **실행 로그**에 나온 **저장 시트 주소**와 **선생님 편집 비밀번호**를 보관합니다. 시트는 선생님 계정에 만들어지며 직접 공유할 필요가 없습니다. 비밀번호를 학생에게 전달하거나 공개 저장소에 올리지 마세요. setup을 다시 실행해도 기존 저장 내용은 지우지 않습니다.
5. **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**을 선택합니다.
6. **실행 사용자: 나**, **액세스 권한: 모든 사용자**로 설정하고 배포합니다. 학교 계정 정책으로 ‘모든 사용자’를 선택할 수 없으면 이 방식의 익명 접속은 지원되지 않습니다.
7. `/exec`로 끝나는 **웹 앱 URL**을 복사합니다. `/dev` 주소는 학생용으로 사용할 수 없습니다.
8. 앱의 **4 노랫말 만들기 → 선생님 설정 · 저장소 연결**을 펼쳐 웹 앱 URL과 편집 비밀번호를 넣고 **연결하기**를 누릅니다.
9. **학생용 주소 복사**로 만든 주소를 학생들에게 나눠 줍니다. 이 주소에는 저장소 URL이 포함되며, 편집 비밀번호는 포함되지 않습니다.

웹 앱 URL을 제작 담당자에게 전달하면 `composer-config.json`의 `endpoint`에 등록해 기본 사이트 주소만으로도 같은 저장소를 열 수 있습니다. 편집 비밀번호는 전달하지 않아도 됩니다.

## 수업에서 사용하기

- 1절이 기본으로 열립니다. 2~5절은 각각 펼쳐서 작성합니다.
- 원래 노랫말과 같은 줄바꿈·음절 칸을 사용하며 띄어쓰기 부분은 간격입니다. 한 칸을 누른 뒤 계속 입력하면 다음 칸으로 자동으로 이어집니다. 받침을 조합하는 동안에는 같은 칸에서 입력합니다. 문장을 붙여 넣어도 칸마다 나누어 들어갑니다.
- **저장**은 글자가 들어 있는 절만 공동 저장하고, 이전 제작 기록에도 남깁니다. 비어 있는 나머지 절은 저장하지 않습니다.
- 학생들이 이 화면을 열어 두고 있으면 약 15초 간격으로 새 저장 내용을 확인합니다. 백그라운드 탭과 기기 절전 상태에서는 늦어질 수 있습니다.
- 아직 저장하지 않은 초안이 있는 기기는 다른 저장으로 덮어쓰지 않습니다. 출력에서 PDF로 보관한 뒤 **저장된 노랫말 확인**으로 새로 불러옵니다.
- **전체 지우기**는 현재 화면의 모든 절을 즉시 비웁니다. 제목과 기존 제작 기록은 유지하고 새 기록은 남기지 않습니다. 지운 상태를 학생들의 패드에도 반영하려면 **저장**을 누릅니다. 노랫말이 들어 있는 상태에서 저장을 누르면 제작 기록이 남습니다.
- **이전 제작 기록**에서 다시 불러오기, 출력를 할 수 있습니다. 다시 불러온 글자를 학생들에게 반영하려면 저장을 누릅니다.
- **출력**은 작성된 절만 A4에 절마다 한 장씩 출력합니다. 출력 창에서 PDF로 저장할 수도 있습니다.
- **크게 보고 부르기**는 작성한 절을 큰 칸으로 보여줍니다.
- **반주 재생**은 뮤키 동요 노래방의 반주 영상을 사용합니다. 영상 제공자가 외부 재생을 제한하거나 학교 네트워크가 차단하면 YouTube 링크에서 확인합니다. 음악 파일을 복제하거나 음성을 추출하지 않습니다.

## 보관과 접근

노랫말과 제작 기록은 수업 주소를 아는 사람이 로그인 없이 읽을 수 있습니다. 학생 이름 등 개인정보 대신 수업용 문구를 넣어 주세요. 편집 비밀번호를 아는 사람만 저장·초기화할 수 있습니다. 비밀번호는 앱의 현재 탭 메모리에만 보관합니다.

편집 비밀번호를 바꾸려면 Apps Script **프로젝트 설정 → 스크립트 속성 → EDIT_KEY**를 바꾸고 저장합니다. 기존 시트와 기록은 남습니다. 코드 수정 후에는 **배포 관리 → 수정 → 새 버전**으로 배포해야 합니다.

구글 Apps Script와 시트의 사용량 제한은 구글 계정 정책을 따릅니다. 이 앱의 시트에서 이름이 ‘현재’와 ‘기록’인 탭을 지우거나 열 순서를 바꾸지 마세요.

## 확인 범위

입력 칸 수·선택 저장·출력·비밀번호·동시 저장 충돌·초기화와 기록 복구는 자동 검사합니다. 실제 구글 계정 권한과 웹 앱 배포 URL이 연결되어야 여러 기기에서의 저장·조회까지 최종 확인할 수 있습니다.
